# Thread & Trend – Fashion Store

## Project Description
Thread & Trend is a simple and responsive fashion website that displays clothing and accessories for men and women.

## Objective
The main objective of this project is to create a user-friendly fashion website using HTML, CSS, and JavaScript.

## Features
- Attractive home page
- Fashion product collection
- Category filters for Men, Women, and Accessories
- Add to Cart button with item counter
- Responsive design for mobile and desktop
- About section
- Newsletter subscription message

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html` – Website structure
- `style.css` – Website design and layout
- `script.js` – Website interactive features

## How to Run the Project
1. Download or clone the project.
2. Keep all three files in the same folder.
3. Open `index.html` in a web browser.
4. Explore the website and test its features.
